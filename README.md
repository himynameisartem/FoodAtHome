# Food At Home

**Food At Home** is an iOS app that helps users track the food they have at home, manage expiration dates, and create and share food lists.  
The app is built using the **Clean Swift (VIP)** architecture and supports both **English and Russian** localizations.

---

## Features

- Track food items and their expiration dates
- Create and manage categorized food lists
- Share food lists with others
- Receive **local notifications** when food is about to expire
- Custom views, animations, and transitions
- **Dark and Light theme** support
- Fully localized (English 🇺🇸 and Russian 🇷🇺)

---

## Architecture

The app follows the **Clean Swift (VIP)** architecture pattern:
- **View** – Handles UI rendering and user interactions
- **Interactor** – Contains business logic
- **Presenter** – Prepares data for display
- **Router** – Handles navigation

This modular and testable architecture ensures code clarity and maintainability.

---

## Data Storage

- Uses **Realm** for local database storage
- Fast and efficient data handling even with large food lists

---

## Tech Stack

- Swift
- UIKit
- Clean Swift (VIP)
- Realm
- UserDefaults
- Local Notifications
- Localization (Base → en, ru)

  # Еда Дома (Food At Home)

**Еда Дома** — это iOS-приложение, которое помогает отслеживать продукты у себя дома, контролировать сроки годности, создавать списки продуктов и делиться ими с другими.  
Приложение построено на архитектуре **Clean Swift (VIP)** и поддерживает локализацию на **русском и английском языках**.

---

## Основные возможности

- Учёт продуктов и контроль сроков годности
- Создание и управление списками еды
- Возможность делиться списками
- Уведомления о скором истечении срока годности
- Кастомные представления, анимации и переходы
- Поддержка **светлой и тёмной темы**
- Полная локализация (английский 🇺🇸 и русский 🇷🇺)

---

## Архитектура

Приложение построено по шаблону **Clean Swift (VIP)**:
- **View** – отображает интерфейс и реагирует на действия пользователя
- **Interactor** – содержит бизнес-логику
- **Presenter** – форматирует данные для отображения
- **Router** – управляет навигацией

Такой подход делает проект модульным, тестируемым и легко расширяемым.

---

## Хранение данных

- Используется **Realm** для локального хранения данных
- Быстрая работа даже с большим количеством продуктов
